# AI Usage Policy

English | [日本語](AI_POLICY.ja.md)

## Use of AI in Development

I use AI as a support tool in development. The main uses are as follows:

- Code refactoring
- Consultation and discussion regarding complex processing and design
- Creating and translating documentation
- Assisting with Git management and release work

The use of AI is limited to the scope that I myself can understand and review. Rather than adopting AI proposals or changes as they are, human verification and necessary testing are performed, and I take final responsibility and make the ultimate decisions.

My products include code and documentation generated or edited using AI. If you do not agree with this policy, please refrain from using them.

## Contributions to Other Projects

When I contribute to other projects, I comply with the license, contribution rules, and policies regarding AI usage of that project. If the use of AI is prohibited or restricted, I will follow that policy.

## Contributions to This Project

For contributions to this project, please refer to the [Contribution Guide](CONTRIBUTING.md).
