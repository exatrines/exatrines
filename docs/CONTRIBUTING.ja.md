# コントリビューションガイド

[English](https://github.com/exatrines/exatrines/blob/main/CONTRIBUTING.md) | 日本語

コントリビューションはいつでも大歓迎です！バグ報告、機能の提案、ドキュメントの改善、プルリクエストなど、さまざまな形での協力がプロジェクトをよりよくしてくれます。

## コントリビューションの手順

AIを使うかどうかにかかわらず、以下の点を守ってください。

- **変更が必要な理由を、あなた自身の言葉で説明してください。**
- 自分の変更内容を理解・確認し、徹底的に検証してください。
- 対象プロジェクトのライセンスと貢献ガイドラインに従ってください。

バグを報告する際は、発生している問題、期待する動作、再現手順を記載してください。可能であれば、関連するバージョン情報やログも添えてください。共有する前に、個人情報や機密情報は必ず削除してください。

プルリクエストでは、変更内容とその理由、検証方法を説明してください。把握している制限や実施できなかった確認があれば、それも明記してください。レビューしやすいように、変更は必要な範囲に絞り、リポジトリの既存の構成やスタイルに従ってください。

大きな変更を考えている場合は、プルリクエストを提出する前にぜひご連絡ください。進め方を相談しながら、一緒に取り組みましょう！

## AIを利用したコントリビューション

AIを利用した貢献も、通常の貢献と同じ条件で歓迎します。ただし、自分で理解・確認し、責任を持てる変更のみを提出してください。AIが生成した説明やテスト結果は、あなた自身の理解や検証の代わりにはなりません。
