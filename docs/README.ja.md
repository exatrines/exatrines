# 開発への取り組み

[English](README.md) | 日本語

開発でのAIの使い方と、私のプロジェクトへの参加・他のプロジェクトへの貢献についての方針をまとめています。

## 開発でのAIの使い方

私は、以下の作業のサポートにAIを使用しています。

- コードのリファクタリング
- 複雑な処理や設計の相談
- ドキュメントの作成・翻訳
- Git管理やリリース作業

**AIの利用は、私自身が変更内容を理解し、レビューできる範囲に限っています。** 提案や変更を自分で確認し、必要な検証を行ったうえで、最終的な判断と成果物に責任を持ちます。

私のプロジェクトには、AIを利用して生成・編集したコードやドキュメントが含まれます。AIを使用したソフトウェアの利用を避けたい方は、この点を踏まえて利用をご判断ください。

## 私のプロジェクトへの参加

AIを利用したプルリクエスト（PR）を含め、コントリビューションを歓迎します。変更の目的、内容、品質に基づいて判断します。

AIの利用の有無にかかわらず、以下をお願いします。

- **なぜその変更が必要なのかを、あなた自身の言葉で説明してください。**
- 提出する変更内容を理解し、自分でレビューと必要な検証を行ってください。
- 対象プロジェクトのライセンスとコントリビューションルールを守ってください。

各リポジトリに `CONTRIBUTING.md` がある場合は、プロジェクト固有の案内も確認してください。

## 他のプロジェクトに貢献するとき

私は、貢献先のライセンス、コントリビューションルール、AI利用に関する方針を遵守します。AIの利用が禁止・制限されている場合も、その方針に従います。
